# This is the workflow on Dec 20, 2025 using UKF based triangularization

1. Import & edit pose data in pose editor

2. Export edited keypoints to JSON format by running  scripts\export_real_persons_to_json.py in Blender. This exports all persons from the scene to C:\temp\blender-pose-editor-export. Takes some time.

3. Triangulate using my UKF based algoritm (prack_multi_camera.py) Inputs:
   * base_dir (the OpenPose project directory) with 2D pose JSON files
   * OpenPose calibration
   * Produces TRC file with 3D keypoint coordinate estimatesd

4. Create OpenSim model that matches the data
   * In  pose-editor addon, triangulate time range that has the person in quite straight position
   * Run scale armature
   * edit the armature & symmetrize arms & hands (for some reason left had has currently weird rotation)
   * Export OpenSIm model

5. Run IK in opensim
   * Open the model created in previous step
   * USe TRC data from step 3
   * Save results as `.mot` file
   * Optionally reduce weight markers in fingers & feet

6. Convert OpenSim results to BVH format
   * `python C:\Users\HarriKaimio\projects\pose-editor\scripts\opensim_to_bvh.py --model <osim model> --motion <.mot file from OpenSIm> -o  <output.bvh> --root-body hips --framerate 120`

7. Import the BVF animation
   * For Reallusion tools
    * Load the BVH file to Character Creator
      * Select "Create Humanoid"
      * Map CC's HIK bones to the file
      * Save characterization (Save icon in the bone mapping panel)
    * Open iClone
      * Add character to project
      * Select "Import external motion"
      * Select the characterization from privuous step as motion profile (not sure abotu the term, the topmostl selection in import dialog)
      * Import
